Privacy & Data Protection Notice

1. Ephemeral Image Handling: Camera frames captured for obstacle and hazard detection are processed in memory and transmitted directly to the Google Gemini API over encrypted TLS/HTTPS. No images are permanently stored on remote servers.

2. In-Browser API Key Storage: Your Gemini API key is stored exclusively in your local browser's localStorage. It is never logged or routed to third-party proxies.

3. Local Audit History: Proximity measurements and hazard timestamps are kept locally on this device and can be cleared at any time via the "Clear" button.

4. Medical & Navigation Disclaimer: Third Eye AI is an experimental secondary mobility aid. It is not certified as an autonomous navigation system. Users should always rely on their white cane and trained mobility protocols.
